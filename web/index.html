Wikipedia editions are branches. This is the merge tool.

Search for an article to see how the Finnish, Swedish and English editions agree, conflict, or leave gaps in each other.

  • Conflict the editions contradict each other
  • Gap one edition has a fact the others lack
  • Agree every edition says the same thing

Every verdict carries receipts: the source passage, the revision id and a link back to Wikipedia. Press ? for keyboard shortcuts.

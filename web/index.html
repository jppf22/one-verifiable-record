Cross-language reference check

Compare editions, claim by claim

Pick an article to compare it with pages about the same subject in the Finnish, Swedish, and English Wikipedias. Each finding is read from the selected article’s point of view.

  • Conflict this page and a counterpart page contradict each other
  • Missing here a counterpart page states it, this page doesn't
  • Only here this page states it, no counterpart page does
  • Agree every counterpart page that has the fact says the same thing

Every finding includes its source passage, revision ID, and a link back to Wikipedia. Press ? for keyboard shortcuts.

About this tool

One Verifiable Record treats language editions as parallel records of the same subject. It highlights differences for people to inspect; it does not decide which edition is correct.
